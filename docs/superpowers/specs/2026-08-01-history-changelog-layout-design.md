# 2.12.0–2.14.1 更新记录整理设计

## 目标

参照 2.8.0 的结构，整理 `items/History.html` 中 2.12.0、2.13.0、2.13.1、2.14.0 和 2.14.1 的更新记录。每个版本的全部条目由一个 `.update-list` 外框包裹，并统一使用以下分类：

1. 新功能
2. 逻辑变更与优化
3. 缺陷修复

只显示有内容的分类，不生成空标题或空列表。

## 内容整理规则

- 保留每项改动的核心信息，不遗漏独立的用户可见变化、安全修复或计算逻辑变化。
- 合并同一工具、同一主题下语义高度重叠的相邻条目，减少重复描述。
- 分类顺序固定为“新功能”“逻辑变更与优化”“缺陷修复”。
- 新增能力使用 `tag new`，行为或体验调整使用 `tag improved`、`tag ux` 或 `tag ui`，问题修复使用 `tag fixed`。
- 安全加固、错误结果修正和显示异常归入“缺陷修复”；正常行为调整、交互改善、文档与测试保障归入“逻辑变更与优化”。
- 不修改版本号、发布日期、时间线顺序或 2.11.0 及更早版本。

## 各版本整理方向

### 2.14.1

- 新功能：浏览器回归测试。
- 逻辑变更与优化：研发工具任务防抖、自然月/年计算、站点专属链接清理规则与原链接保留。
- 缺陷修复：Markdown 与文本渲染安全、夏令时和农历日期计算、业务参数误删。

### 2.14.0

- 新功能：轮胎选择器、火星文转换器。
- 逻辑变更与优化：轮胎规格约束与自动收敛、两项工具的布局和视觉优化。
- 缺陷修复：轮胎比例和深色主题显示、火星文转换器深色主题样式。

### 2.13.1

- 缺陷修复：侧栏分组结构与更新卡片间距。

### 2.13.0

- 逻辑变更与优化：主题同步、代码格式化监听、版本与文档同步、回归保障。
- 缺陷修复：Markdown 和链接历史安全、世界时间、万年历、时间计算、极速计算与页面编码问题。

### 2.12.0

- 新功能：接口带宽计算及其负载、显示器、预设和科普能力。
- 逻辑变更与优化：接口模式、负载表格、计算摘要、默认值与视觉层级。
- 缺陷修复：窄布局字段显示和切换负载类型后的备注更新。

## 验证

- 检查 2.12.0–2.14.1 每个版本恰好包含一个 `.update-list`。
- 检查分类标题仅使用三个允许值，顺序正确，且没有空分类。
- 检查版本号、日期、版本顺序及 2.11.0 以前内容未改变。
- 运行现有静态回归测试与浏览器回归测试。
