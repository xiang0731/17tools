# 图片处理模块设计

## 目标

在 17Tools 中新增一个本地图片处理工具，提供三个互不共享状态的功能：文字水印、单张裁切、目标体积/质量联动压缩。图片只在浏览器内处理，不上传服务器。

## 非目标

- 图片 Logo 水印、盲水印、多行富文本水印
- 裁切标签的批量处理
- GIF / BMP / HEIC / RAW 等格式
- 在线滤镜、调色、拼图、格式互转（压缩输出 JPEG/WebP 除外）
- 服务端编解码或 Squoosh WASM 编解码器

## 接入方式

新增独立页面 `items/ImageProcessor.html`，侧栏「其他工具」中增加「图片处理」，放在现有「火星文转换」之后。同步更新：

- `index.html` 导航项（图标 `fa-image`，无 `data-protected`）
- `items/Welcome.html` 工具数量（当前 17 → 18）
- `items/History.html` 新次版本（当前 2.14.1 → 2.15.0）「新功能」条目
- `README.md` 工具列表与目录
- `js/version.js` 的失败回退版本号改为 `2.15.0`（页面展示仍以 History 为准）

主题使用 `css/theme.css` 变量，跟随全局深色/浅色。布局参考 WiFi 二维码页：左侧预览、右侧参数，窄屏上下堆叠。

## 页面结构

页面标题「图片处理」。其下三个标签，默认打开「添加水印」：

1. 添加水印
2. 图片裁切
3. 图片压缩

每个标签拥有独立的文件列表、预览、参数和导出状态。切换标签不迁移、不清空另一标签的图片。关闭页面后图片不保留；水印参数和压缩输出格式写入 `localStorage` 键 `17tools-image-processor`。

## 共同规则

### 输入

- 接受 `image/jpeg`、`image/png`、`image/webp`（含 `.jpg` / `.jpeg` / `.png` / `.webp`）。
- 支持点击选择和拖拽到预览区。
- 加载时按 EXIF 方向校正（`createImageBitmap` 的 `imageOrientation: 'from-image'`，不支持时回退为普通 `Image`）。
- 单文件上限 20 MB。一次最多 20 张（裁切标签强制 1 张；若一次选多张，只取第一张并提示）。
- 超限、类型不符的文件不进入列表，并立即说明原因。

### 预览与导出命名

- 预览始终针对当前选中的一张图。
- 单张成功：直接下载该文件。
- 水印/压缩多张成功：用 JSZip 打包下载。ZIP 内保留处理后的文件名。ZIP 生成失败时改为逐张触发下载，并提示原因。
- 文件名：原名去掉扩展名 + 后缀 + 新扩展名。
  - 水印：`{stem}_watermarked.{ext}`
  - 裁切：`{stem}_cropped.{ext}`
  - 压缩：`{stem}_compressed.{ext}`
- 水印和裁切尽量保留原格式（jpeg→jpeg、png→png、webp→webp）。压缩输出由用户选择 JPEG 或 WebP。

### 第三方库

- Cropper.js 1.6.2（裁切交互），CDN 引入。
- JSZip 3.10.1（批量打包），CDN 引入。
- 水印和压缩不引入第三方库，使用 Canvas 2D。

## 单元划分

| 单元 | 职责 | 依赖 |
| --- | --- | --- |
| `js/image-processor-core.js` | 格式校验、文件名、水印几何、压缩策略（质量二分、必要时缩放）、目标体积解析。可在 Node 测试。 | 无 DOM |
| `items/ImageProcessor.html` | 标签、上传、预览、Cropper 实例、Canvas 绘制、ZIP 下载、主题 | core + Cropper.js + JSZip |
| 导航/文档文件 | 入口与说明 | 无 |

Core 以 UMD 导出 `ImageProcessorCore`，风格对齐 `js/tire-selector-core.js`。

## 添加水印

功能对齐常见开源水印（如 watermark-js-plus 的图片文字水印）：单行文字、透明度、旋转、九宫格定位、对角线平铺。不做页面防篡改、盲水印、图片 Logo。

### 参数

| 参数 | 默认 | 范围/取值 |
| --- | --- | --- |
| 文字 | 空 | 去掉首尾空白后为空则禁止导出 |
| 字号 | 短边的 5% | 1%–20%，批量时每张按各自短边计算，观感一致 |
| 颜色 | `#ffffff` | 颜色选择器 |
| 透明度 | 50% | 0–100 |
| 旋转 | 0° | -90–90 |
| 位置 | 右下 | 九宫格：左上/上/右上/左/中/右/左下/下/右下 |
| 平铺 | 关 | 开后忽略九宫格，按间距重复；间距默认短边的 18%（8%–40%） |

字体固定为系统中文字体栈：`"PingFang SC", "Microsoft YaHei", sans-serif`。距边缘为短边的 3%。开启平铺且旋转仍为 0° 时，把旋转设为 -22°（典型斜向平铺）；用户之后仍可改。关闭平铺不改旋转。

多张时在预览下方显示缩略图条，点击切换当前预览；参数始终作用于整批。预览随参数实时重绘当前图。批量时同一套参数套到每张图（字号、间距按该图短边换算）。

### 导出格式

在原图 Canvas 上绘制水印后按原 MIME 导出。JPEG / WebP 质量固定 0.92；PNG 用无损默认。

## 图片裁切

仅单张。使用 Cropper.js：拖框、滚轮/触控缩放、移动。

### 工具条

- 比例：自由、1:1、4:3、16:9、3:4、9:16。默认自由。
- 顺时针 90°、逆时针 90°。
- 水平翻转、垂直翻转。
- 重置：恢复原图方向、比例和裁切框。

导出 `getCroppedCanvas()` 的结果，按原 MIME 编码（JPEG / WebP 质量 0.92，PNG 无损）。裁切框无效或画布无法生成时提示重新选择，不下载空文件。

## 图片压缩

可批量。目标是在尽量不缩小分辨率的前提下减小体积，并让「质量」和「目标体积」双向联动。

### 参数

- 质量滑杆：1–100，默认 80，对应 Canvas `quality` 0.01–1.00。
- 目标体积：数字 + 单位 KB 或 MB；快捷选项 200 KB、500 KB、1 MB。内部换算为字节。
- 输出格式：JPEG（默认）或 WebP。
- 预览旁展示：原体积、结果体积、节省比例、结果宽高。未出结果时不显示节省比例。

### 联动规则

页面记住最近一次改的是「质量」还是「目标体积」（`controlMode`）：

- 改质量：按该质量、原尺寸编码当前预览图，把目标体积输入更新为实际字节（换算成合适的 KB/MB 显示）。批量导出时每张都用这一质量，体积可以不同。
- 改目标体积或点快捷选项：对当前预览图跑压缩策略，把质量滑杆更新为实际采用的质量。批量导出时每张各自跑同一目标体积，质量可以不同。

滑杆和数字输入防抖 150ms，避免连续拖动时卡顿。载入或切换当前图后，按当时的 `controlMode` 自动出一次预览（初始为质量模式、质量 80）。

压缩标签多张时同样使用缩略图条切换预览。

### 压缩策略（core）

输入：源像素尺寸、原字节数、目标字节数、输出 MIME、起始质量。

1. 仅当 `controlMode === 'size'` 且目标体积 ≥ 原体积：不重编码，返回原文件字节，并标记 `passthrough: true`（页面提示「已小于或等于目标，未再压缩」）。
2. 否则在质量 `[minQuality, 1]` 上二分（策略搜索的 `minQuality = 0.3`），在**原分辨率**下编码，取不超过目标的最高质量。质量滑杆在质量模式下仍可低于 30，不受此下限限制。
3. 若质量 0.3 仍超标：按 0.9 步进缩小边长。短边下限为 `min(256, 原图短边)`，即从不放大。每步再从 0.3–1 二分质量，直到达标或碰到下限。
4. 仍超标：返回当前能得到的最小结果，标记 `hitTarget: false`。页面必须说明未达到目标，并给出实际体积。

浏览器编码在页面层用 `canvas.toBlob` 完成。core 只负责：解析目标体积、质量与体积显示换算、二分边界、缩放步进、是否 passthrough / hitTarget。页面把「在某质量、某尺寸下编码得到的字节数」作为回调交给策略函数，便于测试时注入假编码器。

WebP 在运行时探测 `canvas.toBlob('image/webp')`；不支持则禁用 WebP 选项并说明。

## 数据流

```text
用户选文件
  → 校验类型/大小/数量
  → 读入内存（ArrayBuffer + 校正后的 ImageBitmap）
  → 当前标签预览

水印参数变化 → core 计算绘制几何 → 预览 Canvas 重绘
裁切操作     → Cropper.js 更新选区
压缩参数变化 → 策略 + toBlob → 更新预览与体积数字

导出
  → 对列表中每张执行该标签处理
  → 成功项下载或写入 ZIP
  → 失败项留在页面错误列表，不中断其余文件
```

三套文件列表互不引用。内存中的 Object URL 在文件被移除或页面卸载时 `revoke`。

## 异常处理

| 情况 | 行为 |
| --- | --- |
| 非 JPEG/PNG/WebP | 不加入列表，提示仅支持这三种 |
| 单文件 > 20 MB | 不加入列表，提示超限 |
| 超过 20 张 | 只收下前 20 张，提示其余被忽略 |
| 裁切一次多张 | 只取第一张并提示 |
| 水印文字为空 | 导出按钮禁用 |
| 当前标签无图 | 导出按钮禁用 |
| 某张解码失败 | 跳过，错误列表记录文件名和「无法读取」 |
| 某张未达目标体积 | 仍放入结果，错误列表记录「未达到目标体积，实际 xx」 |
| 裁切画布失败 | 不导出，提示重新选择 |
| JSZip 失败 | 改为逐张下载并提示 |
| 拖入非图片 | 与类型不符相同处理 |

错误列表显示在该标签导出按钮下方，换一批文件时清空。
